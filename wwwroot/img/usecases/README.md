# Use Cases photos

One photo per industry. The Use Cases page (`Views/UsedCases/Index.cshtml`)
looks for a file named after the industry's slug and shows it automatically —
no code change needed. Until a file exists, that tile shows a coloured
placeholder instead.

## File names

Any of `.jpg`, `.jpeg`, `.webp` or `.png` works (checked in that order).

## Size

Landscape, 4:3, about **1600 × 1200**, under ~400 KB each. The tiles crop to
fill, so keep the subject near the centre. Tiles 1, 6, 11 and 16 are drawn
twice as wide on desktop and the last (HVAC) runs full width, so keep the subject centred — the crop is wider there.

Use photos you have the rights to: the client's own, or licensed stock.
